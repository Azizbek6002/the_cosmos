# NASA_by_Algorix

> **NASA Space Apps Challenge 2026 // CH-08: Flame in Freefall**  
> **Physical Sciences Informatics (PSI) Spacecraft & Extraterrestrial Habitat Fire Safety Interface**

An award-winning, futuristic Awwwards-level interactive platform engineered for planetary fire safety, microgravity combustion modeling, and extraterrestrial habitat telemetry across the Solar System (Moon/Artemis, Mars, Low Earth Orbit/ISS, Titan, Europa, and deep space stations).

---

## 🚀 Core Mission & Purpose

In microgravity and reduced gravity, fire behaves unpredictably. Without natural buoyant convection, flames do not rise; instead, they form quiescent, spherical diffusion envelopes and can transition into invisible low-temperature **"Cool Flames"** (NASA FLEX discovery) that silently generate toxic carbon monoxide (CO).

This platform harnesses NASA flight data (FLEX, BASS, SAFFIRE, ACME) to provide:
1. **Planetary Fire Telemetry**: Compartment vulnerability rankings, oxygen limiting concentration (LOC), flame spread velocity, and CO hazard metrics for 7 celestial bodies.
2. **Tactical Action Directives**: Emergency crew action protocols, automated HVAC shutdown, nitrogen overpressure barriers, and lunar regolith in-situ smothering.
3. **Planetary Database**: Editorial 1:1 scientific archives with planetary coordinates, distance, chemical resources, and barcode telemetry.
4. **Interactive Fire Simulator & HUD**: Real-time simulation of microgravity combustion physics across different gravitational regimes (0g, 0.14g, 0.166g, 0.38g, 1.0g).

## 🌌 Platform Modules

- **01 // DASH**: Minimalist cinematic hero interface introducing the mission directives and core scientific objectives.
- **02 // SOLAR HUD**: 1:1 cybernetic telemetry interface featuring a central photorealistic 3D globe, habitat compartment rankings, real-time sparkline telemetry curves, and tactical Q&A action drawers.
- **03 // PLANETS**: High-density brutalist editorial scientific archive for all planetary exploration targets with orbital coordinates and flame dynamics dossiers.
- **04 // SIMULATOR**: Cybernetic tactical mission table with planetary orbit selectors and actionable fire suppression protocols for astronaut crew safety.

## 📦 Getting Started

### Prerequisites

- Node.js (v18.0 or newer recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone git@github.com:Azizbek6002/NASA_by_Algorix.git

# Enter the directory
cd NASA_by_Algorix

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
